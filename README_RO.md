# TitanScript STANDARD 2.5 — documentație și exemple

[**English**](README.md) · [Referința SoftCAD](https://softcad.ro/documentatie-tss)

**Acesta este un pachet de documentație, nu un interpretor standalone.** Conține referința bilingvă TitanScript STANDARD 2.5.0 RC2.1 și două exemple `.tss` disponibile deja în centrul de dezvoltatori SoftCAD.

- `docs/tss-standard-2.5-ro.md` și `docs/tss-standard-2.5-en.md`: limbaj, funcții, module, limite.
- `examples/01_limbaj_standard_25.tss`: exerciții de bază.
- `examples/02_baza_tdb3_standard_25.tss`: exemplu care **scrie într-o bază locală TDB3**; rulează numai pe date de probă.

Runnerul standalone, Shield/TSX, interpretorul proprietar, motoarele CAD și codecurile comerciale nu sunt incluse. Exemplarele pot necesita runnerul TSS integrat în FileCommander 4.4.3. Fișierele din această arhivă sunt sub Apache-2.0 în sfera indicată de `NOTICE.md`; codul absent nu este licențiat.
